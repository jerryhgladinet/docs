########################
Upgrade CentreStack
########################

We publish updated notes to our public blog forum called `CentreStack Blog`_. It is recommended that you perform an update if your self-hosted CentreStack and clients are three months or older.

Using the GUI Installer to Upgrade
---------------------------------------

To install an update go to your `Partner Portal`_ (Self-Hosted CentreStack -> Download) and download the GUI installer.

.. image:: _static/image_s2_5_1_v3-03192025.png

When you run the GUI installer, it will detect the existing installation and perform an upgrade.
